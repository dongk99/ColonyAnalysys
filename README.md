# ColonyAnalysys

RimWorld 1.6 mod. Harmony required, mainly due to how mod collects botched construction.
Adds an **Analysys** sub-tab to the History window.

 - Records when mental breaks happen/how long pawns have been on risk for.

 - Shows % of botched construction/harvest.
 
 Mod does not show data prior to installation, because base game doesn't save pretty much all of the botches/break data.
 
 Try not to cry if your stats look bad. :)
